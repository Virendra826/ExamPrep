# Seed Data Guide

> **WARNING:**
> **Do not run this seed script against a production database.**
> The credentials and IDs generated by this script are meant strictly for local development and testing.

---

## 1. Overview

The seed script (`backend/prisma/seed.ts`) populates a clean local database with realistic development data required to develop, test, and evaluate the ExamPrep platform without needing manual question entry.

The script is **fully idempotent** using unique constraints and upserts. Re-running `npx prisma db seed` at any time is safe and will never duplicate records.

## 3. Academic Taxonomy

### Subjects & Chapters (3 Subjects, 9 Chapters total)

1. **Compiler Design**
   - *Lexical Analysis* (Tokens, regular expressions, transition diagrams, finite automata)
   - *Syntax Analysis & Parsing* (Context-free grammars, LL(1) parsing, LR/LALR parsing)
   - *Code Generation & Optimization* (DAG representations, basic blocks, code motion)

2. **Operating Systems**
   - *Processes & CPU Scheduling* (Process states, context switching, scheduling algorithms)
   - *Memory Management & Paging* (Paging, TLBs, page replacement, Belady's anomaly)
   - *Deadlocks & Synchronization* (Coffman conditions, Banker's algorithm, semaphores)

3. **DBMS (Database Management Systems)**
   - *Relational Model & ER Diagrams* (ER entities, candidate keys, referential integrity)
   - *SQL & Relational Algebra* (Selection, projection, joins, normalization/BCNF)
   - *Transactions & Concurrency Control* (ACID properties, serializability, 2PL protocol)

---

## 4. Question Bank (30 Questions)

Each of the 3 subjects is seeded with **10 questions** (30 questions total):
- **Status**: All marked `ACTIVE`.
- **Question Types**: 15 `CONCEPT` questions + 15 `PYQ` questions (5 of each per subject).
- **Difficulty**: Realistic distribution across `EASY`, `MEDIUM`, and `HARD`.
- **Options**: JSON format containing 4 options (`A`, `B`, `C`, `D`).
- **PYQ Metadata**: PYQ questions include historical exam references (e.g., `GATE CS 2020–2023`, `ISRO CS`).

---

## 5. How to Run the Seed Script

From the repository root:
```bash
npm run db:seed
```

Or directly inside `backend/`:
```bash
cd backend
npx prisma db seed
```
